2026年9月27日に Chromium と Playwright で撮影した。X の投稿ページは空白だったため、X 公式の `platform.twitter.com/embed/Tweet.html` に投稿 ID を指定して表示した。投稿者とアカウント名と本文と投稿日を含み、PLAID の投稿には開催告知の画像とリンクプレビューも含む。画像内の原文と表示色は変更していない。

撮影時の viewport は 1100 × 1600、deviceScaleFactor は 2、colorScheme は light、タイムゾーンは Asia/Tokyo。投稿者のアイコン上端から投稿日直後までを撮影した。返信では親投稿を撮影範囲から除いた。ナビゲーションと返信入力欄は含まない。リンクプレビュー内の省略表示は、撮影時の公式埋め込みと同じである。

スライドでは縦横比を維持して中央に表示する。下部の説明は 24px と 32px の行高、見出しは 36px と 40px の行高とし、M PLUS 2 を使う。画像と下部の投稿リンクから元の投稿を開ける。

投稿の日時と撮影範囲と画像寸法は `capture.json` に記録する。コミュニティの設立と開催までの経緯は発表者の経験として説明し、PLAID の投稿は開催前の告知として掲載する。
