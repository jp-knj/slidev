ページ 10　Astro v1
改稿前の参考時刻：01:50 から 02:20（30 秒）
発話 485 文字。改稿後の所要時間は未計測。
進行：クリックなし。発話後に次へ進む。

発話
Astro は Go Compiler と Vite に移行しました。
Astro でも Vite の改善や Rollup のプラグインを利用できることが、移行を選んだ理由の一つでした。当時の話は下にリンクを貼っているので、後で確認してみてください。
JavaScript からは WASM を介して Compiler を呼びます。Compiler が Astro のコードを変換して、Vite につなぎます。
Nate Moore が挙げた Go の選定理由は、esbuild が Go だったことと、学びやすかったことです。本人も、深くは考えなかったと書いています。
ただ、実装を見ると Go を選んだ利点がありました。Compiler の Parser は、Go 公式の HTML5 Parser を fork したものです。CSS のパースには esbuild の CSS Parser を取り込んでいます。参考になる実装を、そのまま土台にできる言語でした。
一方で、JavaScript を完全にパースする仕組みは持っていません。これが後半で話す、波かっこと AST の問題につながります。
